# Правила GitHub-репозитория

Репозиторий: https://github.com/SosnovichIvan/moy-mir

Требования пользователя:

- `main` и `develop` изменяются только через pull request.
- PR требуют одобрения владельца `SosnovichIvan`; `.github/CODEOWNERS` назначает его для всех файлов, включая сам CODEOWNERS.
- Только `SosnovichIvan` может слить PR без approval. Исключение ruleset — For pull requests only; прямые push оно не разрешает.
- Другим пользователям, ролям и приложениям bypass не предоставляется.

Дополнительные настройки: линейная история, squash merge, запрет force push и удаления защищённых веток, закрытие обсуждений перед слиянием, сброс устаревших approvals при новых изменениях. Рабочие ветки после слияния удаляются автоматически.

Обязательные CI-статусы и порог покрытия ≥90% будут подключены после реализации проверок на согласованном этапе DevOps. Нельзя считать наличие правил агентов эквивалентом работающей проверки GitHub Actions.

Агент создаёт рабочую ветку и PR; доступ через аккаунт владельца не даёт агенту права самостоятельно обходить обязательное ревью в последующих задачах. Слияние без approval — только по явному указанию пользователя для конкретного PR. Первичная настройка этих правил выполняется в рамках запроса пользователя о настройке репозитория.
