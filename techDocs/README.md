# Документация «Мой МИР»

Дата: 2026-09-19. По прямому запросу пользователя ведётся **дизайн и поэтапная реализация frontend-библиотеки**: направление 02 утверждено, логотип B «Свой круг» предварительно выбран. FE-19 принята после слияния PR #11; предложение FE-20 ожидает согласования. Незакрытые вопросы аналитики остаются в журнале согласований.

В репозитории есть визуальный референс, проектные документы, frontend-каркас A–C, каталог тем и Selection (FE-15), Button/IconButton (FE-13), Field (FE-14) с локальными проверками и workflow CI. Продуктовые функции, инфраструктура развёртывания, схемы БД и API пока не реализованы. [Запуск каркаса](../apps/frontend/README.md), [ADR-002](architecture/ADR-002-frontend-foundation.md).
