# frontend-collaboration: Запросы и отчёты

## Статус

Внутренний модуль frontend. Границы развёртывания уточнены пользователем; детали модулей и стеки — предложения. Реализация отсутствует, проверки кода не выполнялись. Этап — аналитика.

## Ответственность, данные и зависимости

Создание запроса, результата, внутреннего отчёта и выбор получателей; generated API core/collaboration. Без кнопок PDF/экспорта.

Общая архитектура: [решения](../../architecture/proposal.md). Сценарии и предлагаемая семантика сжатия: [продукт](../../product/vision-and-v1.md). Приватные права проверяются при каждой операции; внутренние зависимости проходят через публичные интерфейсы владельцев данных.

## Контракты

`openApi/frontend/collaboration/` — заготовка, схем пока нет. HTTP-модели, события, модели БД и представлений генерируются по [общим правилам](../../../openApi/README.md). Внутренний модуль не становится сетевым сервисом из-за наличия схем.

## Скилы

frontend-engineering, frontend-review. Профили после выбора языка/БД. [Источник и правила](../../process/skills.md). Установлено в общем `agentSkills/`; установка не означает применение к коду. Профили кандидатного стека сверяются перед реализацией.

## Приёмка

Состояния, ошибки, получатели, отзыв, отправленная редакция. Покрытие собственного кода ≥90% по согласованной методике.

## Следующий шаг

Завершить согласование аналитики, затем дизайн. Каталог и локальный AGENTS.md подготовлены; реализация начинается только на соответствующем согласованном этапе. Обновлять фактические изменения, проверки и следующий шаг в конце задачи.
