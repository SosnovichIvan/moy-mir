## Предлагаемый визуальный контракт

| Состояние | Оформление |
| --- | --- |
| Empty | surface, рамка controlBorder 1 px, placeholder muted; очистка скрыта |
| Filled | surface, рамка controlBorder 1 px, значение ink |
| Hover | рамка accent 1 px |
| Focus | рамка focus 2 px |
| Error | рамка danger 1 px и конкретная ошибка под полем |
| ErrorFocus | рамка danger 2 px и отдельный внешний контур focus 2 px с отступом 2 px |
| Disabled | soft / muted, без действий очистки и показа пароля |
| ReadOnly | bg / ink, подпись «Только просмотр», без действий изменения |

Label, Value, Placeholder, Invalid value, Helper и Error message доступны как текстовые свойства; Show helper управляет видимостью подсказки. Примеры ошибок не задают продуктовые правила валидации. В коде ошибка и фокус должны сочетаться независимо; матрица Figma иллюстрирует приоритеты, а не требует ручного prop для CSS-псевдосостояний.

- Высоты однострочного контрола S/M/L: 44/48/56 px. Multiline: минимум 96/112/144 px. Ширина определяется контейнером независимо от размера. Образцы 288/358/448 px не являются фиксированной шириной runtime-компонента.
- Inter 16 px для ввода, Label 14/20 и Caption 12/18; радиус 12 px, промежутки 8 px. Подпись и пояснение переносятся; multiline выравнивается сверху. Рамка фокуса привязана к Control и следует за переносом подписи.
- Очистка и показ пароля имеют область 44×44 px. Очистка доступна только при непустом редактируемом значении, возвращает фокус в поле. Показ пароля сохраняет значение/курсор и меняет доступное имя «Показать пароль» / «Скрыть пароль».
- Select предлагает нативный список браузера/ОС; раскрытое меню не имеет единого макета. ReadOnly у Select — статическое значение без стрелки (нативный select не поддерживает readonly).
- Disabled недоступен для изменения и Tab. ReadOnly для текстовых контролов сохраняет фокус, выделение и копирование. Ошибка связывается с полем через aria-describedby; label остаётся видимым. Эти требования проверяются в коде после согласования дизайна.

## Проверки дизайна

Проверены 144 уникальных варианта, сохранность 30 исходных, размеры контролов и областей действий, отсутствие непривязанных видимых solid fills/strokes. Использованы существующие токены без новых цветов. Визуально просмотрены матрицы, оба листа тем, размеры и длинные подписи на ширине 320 px. Шесть листов содержат 144 экземпляра новых компонентов.

Расчёт по значениям токенов Light/Dark: ink/surface 11,88 / 13,23; muted/surface 6,21 / 7,75; danger/bg 6,33 / 10,40; controlBorder/surface 4,16 / 5,13; focus/bg 6,38 / 9,23. Это проверка выбранных цветовых пар, а не полный аудит доступности.
