## Согласованный визуальный контракт

| Состояние | Оформление |
| --- | --- |
| Empty | surface, рамка controlBorder 1 px, placeholder muted; очистка скрыта |
| Filled | surface, рамка controlBorder 1 px, значение ink |
| Hover | рамка accent 1 px |
| Focus | рамка focus 2 px |
| Error | рамка danger 1 px и конкретная ошибка под полем |
| ErrorFocus | рамка danger 2 px и отдельный внешний контур focus 2 px с отступом 2 px |
| Disabled | soft / muted, без действий очистки и показа пароля |
| ReadOnly | bg / ink, подпись «Только просмотр», без действий изменения |

Label, Value, Placeholder, Invalid value, Helper и Error message доступны как текстовые свойства; Show helper управляет видимостью подсказки. Примеры ошибок не задают продуктовые правила валидации. В коде ошибка и фокус должны сочетаться независимо; матрица Figma иллюстрирует приоритеты, а не требует ручного prop для CSS-псевдосостояний.

- Высоты однострочного контрола S/M/L: 44/48/56 px. Multiline: минимум 96/112/144 px. Ширина определяется контейнером независимо от размера. Образцы 288/358/448 px не являются фиксированной шириной runtime-компонента.
- Inter 16 px для ввода, Label 14/20 и Caption 12/18; радиус 12 px, промежутки 8 px. Подпись и пояснение переносятся; multiline выравнивается сверху. Рамка фокуса привязана к Control и следует за переносом подписи.
- Очистка и показ пароля имеют область 44×44 px. Очистка доступна только при непустом редактируемом значении, возвращает фокус в поле. Показ пароля сохраняет значение/курсор и меняет доступное имя «Показать пароль» / «Скрыть пароль».
- Select предлагает нативный список браузера/ОС; раскрытое меню не имеет единого макета. ReadOnly у Select — статическое значение без стрелки (нативный select не поддерживает readonly).
- Disabled недоступен для изменения и Tab. ReadOnly для текстовых контролов сохраняет фокус, выделение и копирование. Ошибка связывается с полем через aria-describedby; label остаётся видимым. Эти требования проверяются в коде после согласования дизайна.

## Реализация и API

Экспорты из `src/shared/ui`: `TextField`, `TextareaField`, `SelectField`, типы `FieldConfiguration` и `FieldOption`. Данные описаны в `openApi/frontend/field.schema.json`, типы создаёт `npm run generate:ui`. Отдельные наборы Figma Password/PasswordVisible соответствуют одному TextField с переключением состояния.

- Все поля управляемые: обязательны `label`, `value`, `onValueChange(value)`. Значение хранит родитель; ошибки приходят через `error`, компонент не задаёт бизнес-валидацию.
- Общие свойства: `size` s/m/l (по умолчанию m), `helper`, `error`, `placeholder`, `disabled`, `readOnly`. Ошибка заменяет подсказку и задаёт `aria-invalid`; внешний `aria-describedby` объединяется с внутренним. При отсутствии `id` создаётся стабильный уникальный ID.
- TextField: `type` text/email/tel/url/search/password, `clearable` (по умолчанию true). Пароль показывает глаз вместо очистки. Переключение сохраняет значение, диапазон выделения и возвращает фокус. Нативные autocomplete/inputMode/name/required и события передаются input.
- TextareaField: нативный textarea, перенос строк, вертикальное изменение высоты, минимумы 96/112/144 px.
- SelectField: обязательный массив `options` с уникальными value и label, optional disabled. При использовании placeholder значение `''` резервируется для него. Значение выбирается из options; placeholder — необязательный недоступный option. Нет сетевого поиска или собственного popup.
- `className` относится к обёртке, прочие DOM-атрибуты и `ref` — к input/textarea/select. В readOnly Select нативного select нет: значение показывает связанный с label output, hidden input сохраняет name/form/value для отправки; select-ref в этом режиме пуст. Disabled hidden input не отправляется.
- CSS использует действующие токены и SVG библиотеки. Hover, focus и error сочетаются без смены геометрии. Поле не растягивается по высоте из-за соседнего элемента сетки; ширина следует контейнеру. Кнопки действий имеют type=button и собственный keyboard focus.

Каталог: `/?path=/story/field--overview`, отдельные `field--light` и `field--dark`. Примеры содержат работающие значения и демонстрационную проверку имени; это не продуктовая форма R1.

## Проверки реализации и ревью

- `npm run check`: генерация без drift, lint, typecheck, форматирование, 66 unit-тестов. 100% statements/branches/functions/lines собственного runtime-кода на файл, включая Field; исключения не расширялись.
- `npm run build`, `npm run catalog:build` проходят.
- Все 49 тестов каталога (13 для Field) и два production smoke-теста прошли. После визуальной правки выравнивания сетки 13 Field-тестов повторены.
- Проверены Light/Dark на 320/390/768/1440, размеры, 44×44 действия, ввод и очистка, фокус и диапазон пароля, error+focus+hover, readonly/disabled, перенос строк, увеличение текста до 200%, forced colors, эмуляция touch.
- Визуально просмотрены Light 320 и Dark 1440, сопоставлены с согласованной геометрией и токенами. Профильные frontend-review/ui-ux-design: подтверждённых дефектов в проверенном объёме не осталось.
- Ограничения: Firefox/WebKit, физические телефоны и скринридеры не проверены. На этом хосте headless Chromium не выбирает пункты нативного select клавишами даже в отдельном HTML без React. Автотест проверяет его focus и смену значения через selectOption; клавиатура внутри системного popup требует отдельной проверки.
