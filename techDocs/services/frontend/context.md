# frontend: Общий frontend

Правки FE-13 после ревью: компактная ширина от 96 px, центрирование подписи при одной иконке, вращающийся спиннер для обеих кнопок с сохранением размера и reduced motion. 54 unit-теста, 36 тестов каталога, покрытие 100%; [актуальное поведение](button.md#правки-после-ревью-пользователя). Следующий шаг — повторное ревью PR #6.

## Статус

Одно модульное приложение с последовательными продуктовыми релизами R1–R5. Пользователь разрешил начать ранний frontend-блок. Подготовлен каркас A: React 19.3, TypeScript 6.0, Vite 8.3, Tailwind 4.3, ESLint 10 и Prettier. Блок A принят к продолжению сообщением «продолжаем»; [ADR-002](../../architecture/ADR-002-frontend-foundation.md). Блок B реализован: React Router, конфигурация окружения, production browser smoke и workflow CI. CI на PR #3 успешно завершён. Продуктовые функции пока не реализованы. Основа UI-библиотеки C принята к продолжению; FE-15 принят после слияния PR #5. Продолжение D с FE-13 разрешено; новые состояния Button согласованы, FE-13 реализован для ревью.

## Ответственность, данные и зависимости

Shell и предметные разделы, PWA, общее оформление Tailwind. Начат React/TypeScript-каркас. Загрузка разделов одной сборки по маршрутам планируется; runtime MFE отложены.

Общая архитектура: [решения](../../architecture/proposal.md). Сценарии и предлагаемая семантика сжатия: [продукт](../../product/vision-and-v1.md). Приватные права проверяются при каждой операции; внутренние зависимости проходят через публичные интерфейсы владельцев данных.

## Контракты

`openApi/frontend/ui.schema.json`, `selection.schema.json`, `button.schema.json` и `iconButton.schema.json` содержат UI-конфигурацию, типы генерируются json-schema-to-typescript. HTTP-модели, события, модели БД и представлений генерируются по [общим правилам](../../../openApi/README.md). Внутренний модуль не становится сетевым сервисом из-за наличия схем.

## Скилы

frontend-engineering, frontend-review; при дизайне ui-ux-design и ux-writing. Профили после выбора языка/БД. [Источник и правила](../../process/skills.md). Установлено в общем `agentSkills/`; установка не означает применение к коду. Профили кандидатного стека сверяются перед реализацией.

## Приёмка

Mobile first, отсутствие сети, PWA update/rollback, ошибка chunk, logout, общие маршруты. Цель покрытия собственного кода — 100%; для frontend установлен порог 100% на файл по четырём метрикам.
