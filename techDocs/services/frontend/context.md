# frontend: Общий frontend

## Статус

Одно модульное приложение с последовательными продуктовыми релизами R1–R5. Пользователь разрешил начать ранний frontend-блок. Подготовлен каркас A: React 19.3, TypeScript 6.0, Vite 8.3, Tailwind 4.3, ESLint 10 и Prettier. Блок A принят к продолжению сообщением «продолжаем»; [ADR-002](../../architecture/ADR-002-frontend-foundation.md). Блок B реализован локально: React Router, конфигурация окружения, production browser smoke и workflow CI. CI на PR #3 успешно завершён. Продуктовые функции и UI-библиотека пока не реализованы.

## Ответственность, данные и зависимости

Shell и предметные разделы, PWA, общее оформление Tailwind. Начат React/TypeScript-каркас. Загрузка разделов одной сборки по маршрутам планируется; runtime MFE отложены.

Общая архитектура: [решения](../../architecture/proposal.md). Сценарии и предлагаемая семантика сжатия: [продукт](../../product/vision-and-v1.md). Приватные права проверяются при каждой операции; внутренние зависимости проходят через публичные интерфейсы владельцев данных.

## Контракты

`openApi/frontend/` — заготовка, схем пока нет. HTTP-модели, события, модели БД и представлений генерируются по [общим правилам](../../../openApi/README.md). Внутренний модуль не становится сетевым сервисом из-за наличия схем.

## Скилы

frontend-engineering, frontend-review; при дизайне ui-ux-design и ux-writing. Профили после выбора языка/БД. [Источник и правила](../../process/skills.md). Установлено в общем `agentSkills/`; установка не означает применение к коду. Профили кандидатного стека сверяются перед реализацией.

## Приёмка

Mobile first, отсутствие сети, PWA update/rollback, ошибка chunk, logout, общие маршруты. Цель покрытия собственного кода — 100%; для frontend установлен порог 100% на файл по четырём метрикам.

## Следующий шаг

Принять блок B [плана](bootstrap-tasks.md), затем перейти к C: каталог и токены. Локально проходят 18 тестов Vitest (100% lines/statements/functions/branches для трёх runtime-файлов), lint, typecheck, форматирование и сборка. Два Playwright smoke-теста проверяют production-preview в desktop Chromium и эмуляции Pixel 7: переходы, историю, прямую ссылку, refresh и неизвестный адрес. Проверены dev на отдельном порте и HMR без полной перезагрузки, отклонение неверного окружения при сборке. Физические устройства и полная браузерная матрица пока не проверены. [Правила тестирования](../../process/testing.md).
